## Gopeed race 结果

执行 `CXX=clang++ go test -race ./internal/server -count=1 -timeout=150s`，检测到 11 个竞争报告。冲突读写位于 Gopeed v1.9.3 的 `pkg/download/downloader.go`、`pkg/download/model.go`、`pkg/util/timer.go`、`internal/protocol/http/fetcher.go` 与 `fetcher_manager.go`；包括任务切片遍历、任务状态、计时/进度与分片快照序列化。上层服务已通过事件复制状态，未让网页直接读取引擎活动任务指针。

常规集成测试通过不消除此风险。首版应作为本地试用初稿，不能标为生产稳定版；后续需升级至修复版本或对引擎做独立补丁并重新运行竞争与恢复测试。原始日志包含在本地交付证据目录中。

## 资源约束

没有新增网页轮询或断线自动重试。SSE 连接有 25 秒保活；下载引擎运行任务每秒报告进度，服务每 5 秒检查活动任务，连续 120 秒没有进展就停止引擎，限制其内部重试占用。任务、目录分页、递归与网络超时均有上限。关闭时等待检查点有 8 秒上限。

## 精修验收

基线与 A/B/C 均为同一 DOM、固定数据、四个路由、390/768/1440px、浅/深主题。三版都没有 DOM、网格或顺序变化，无横向溢出、无页面脚本错误。A 消除了全部四类点名问题；B 仍有边线对比提示；C 的字体调整在窄屏带来最多 33px 流式位移，A 为 16.5px。未改列数或页面排布。比较见 `docs/design/selection.json`。

测试夹具曾因 HTTP Range 超出末尾时返回了错误 Content-Length 导致端到端测试等待；已修正夹具协议后再完整执行三轮。候选测量等待两帧浏览器布局与组件 updateComplete，不用任意时长延迟伪造稳定结果。

Impeccable 最终检查新增字体族使用频繁警告；依照用户要求只记录在 next-iteration.md，不扩大本轮改动范围。
