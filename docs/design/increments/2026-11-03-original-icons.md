# 增量：复用云析原项目图标

用户明确要求使用原 GitHub 项目的图标。本次差异来自初稿的自制品牌图标与平台首字占位，不涉及接口无数据、字段映射、渲染失败或缓存问题。

## 修改位置

| 位置 | 变化 | 保持的边界 |
| --- | --- | --- |
| `App.vue` 登录页 / 侧栏 `.brand img` | 换用原项目 `icon.png` | 36px / 32px 尺寸及相邻内容不变 |
| `App.vue` 账号行 `.platform-mark` | 平台首字改为对应原 PNG；28px 图片 | 原 44px 容器、行顺序、操作与间距不变 |
| `web/index.html` | favicon 指向同一原 PNG | 页面入口结构不变 |
| `web/public/icons/` | 复制主图标和四个平台图标 | 未处理原图，SHA-256 与上游相同 |

平台图片名称来源于已有账号的平台 ID。未知平台显示已有 MDUI 云图标。品牌旁及平台旁已有可读名称，图片使用空 alt 避免重复朗读。

`web/src/style.css`、MDUI 操作图标、路由、接口及业务逻辑均未修改。已同步构建嵌入资源。测试夹具增加 PNG MIME，二进制冒烟检查改为核验五张嵌入 PNG 与源码完全一致。
