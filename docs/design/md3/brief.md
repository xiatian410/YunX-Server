# 功能、结构与技术约束

用户要求尽量复刻原版 Material Design 3 页面。用户进一步指定：统一依据 YunX Android，电脑和手机使用同一套页面结构；横向宽屏改用 Android 已有的导航栏适配。保留解析、账号、下载、设置四路由及服务端 API / SSE。Vue 3 + MDUI 2；使用原项目图标及 Color.kt 颜色值。

1. 导航按解析、账号、下载、设置排列；电脑使用 80px 导航栏，手机使用底部导航。保持路由可链接及键盘操作。
2. 解析页包含链接、提取码、解析按钮；账号选项、种子入口与平台说明保留。结果仍支持目录、多选、质量与保存目录。
3. 下载改为逐任务卡片；保留筛选、搜索、多选、暂停、继续、取消、删除、预览、下载到本机与事件记录。
4. 账号保留所有平台、多账号及凭据输入；未添加的平台提供账号入口，账号操作收进菜单。没有容量字段时不展示容量条。
5. 设置使用分组条目，点击条目编辑对应设置并明确保存；保持数据校验、失败显示和改密功能。
6. 浅色、深色、跟随系统均保留。无外部字体或图标 CDN，不增加轮询、重试或延时。
7. 完成功能初稿后进行 Taste 四类定位评审；Impeccable 仅改点名位置；同版式三次验收后冻结，保留旧冻结链。

这次用户明确指定以原版为准，属于新的复刻增量；旧版后台式结构不再作为外观基准。精修阶段仍不允许整页重排。技能的随机风格、通用后台比例与原版冲突时，以用户指定的原版为准。
