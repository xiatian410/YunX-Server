# 图标来源

用户要求使用原 GitHub 项目的图标。本次直接复制原文件，没有重绘、压缩、裁剪或改色。图标随网页和 Go 二进制打包，不在运行时请求 GitHub。

主图标用于登录页（36px）、桌面侧栏（32px）、favicon 与 README（120px）；平台图标用于账号列表已有的 44px 图标容器，图片显示为 28px。图像本身均为正方形，保留比例。相邻文字已提供名称，界面图片的 alt 为空以免重复朗读。
