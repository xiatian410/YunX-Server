# 实施与验收

## 阶段 1：功能初稿

提示词：构建 NAS 解析下载服务。网页包含下载任务、链接解析、网盘账号、设置四个路由。桌面使用侧边导航，移动端使用底部导航。Go 服务持久化账号、设置和下载任务；Vue 3 通过 API 与 SSE 获取数据。使用 MDUI 2 组件，按官方 Vue 集成处理 custom elements 和事件。实现登录、退出、修改密码、添加与更新账号、凭据检查、分享目录浏览、选择文件与文件夹、下载入队、暂停、继续、取消、删除记录、明确确认后删除文件、批量操作、并发与限速设置、空态、错误态和加载态。所有数据来自服务端。支持 390、768、1440 像素视口。文案通过统一消息表。服务关闭或失联时显示状态并保留数据。禁止仅有外观但不能执行的控件。

验收：Go 单测/集成测试、类型检查、前端构建、浏览器真实操作；下载内容哈希一致；重启续传；凭据不泄露；有界取消、超时和目录遍历。

## 阶段 2：Taste 评审

保留初稿截图和源码哈希。评审结果只包括四类问题与位置（页面、视口、CSS 选择器、源文件）。不改代码。

## 阶段 3：Impeccable 精修

三个候选均来自相同初稿。只允许评审列出的 CSS 选择器和属性变化，禁止改变 DOM 次序、路由、业务逻辑、网格列数、导航位置或布局模式。新问题写入 next-iteration.md。

## 阶段 4：验收冻结

同一数据和浏览器条件运行 A/B/C。优先所有问题修复，再比较未授权几何变化、DOM 稳定、控制台错误和功能测试；并列取改动最少者。记录选择与源码哈希。选定后停止审美微调。

## 验证级别

本地源码与模拟协议、真实下载引擎、双架构编译、Docker 构建、真实平台账号、实体 NAS、GitHub 提交、部署为独立项目。未执行者不能标为通过。
